# Weather project with API integrations
A dynamic weather forecasting app built with React, utilizing OpenWeatherMap API for real-time weather data. This project marks my first experience integrating API keys into a solo React application.

## Features
Current Weather: Displays real-time weather information for any city.
Search Functionality: Allows users to search for weather by city name. If an incorrect city location is added a broswer alert will pop up notfying the user, furthermore, if a blank city is entered, an alert will pop up notifying the user to enter a city.
Neat UI: Allowing for easy readability of information

## Technologies used
Frontend: React
API: OpenWeatherMap API
Build Tool: Vite
